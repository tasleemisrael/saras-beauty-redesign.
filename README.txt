To publish on GitHub Pages:
1. Create a public repository, e.g. saras-beauty-redesign
2. Upload index.html to the repository root.
3. Open Settings > Pages.
4. Choose Deploy from a branch, main, /(root), Save.
5. Wait for GitHub Pages to publish.

- This is an independent redesign concept, not an approved site.
